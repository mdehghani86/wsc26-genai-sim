# Phase 1b artefact: validated SimPy ED model

This directory holds the canonical SimPy emergency-department model produced in Phase 1b (Section 5.3 of the WSC 2026 paper). It is the input to Phase 2 (Execution) and Phase 3 (Experimentation).

The file was generated by frontier-model vibe coding from the five-part structured prompt described in the paper, then accepted by the Phase 1b validation gate (process logic, connectivity, parallel-vs-sequential, distributions, and theory). The validation harness lives in `legacy-2025/verify_against_queueing_theory.py` and `legacy-2025/capacity_sweep.py`; both were used to confirm that realised utilisation matches Erlang-C / Allen-Cunneen across a 1-8 by 1-12 capacity grid.

## Run

```bash
pip install simpy
python er_simulation.py
```

## Configure

Edit the `settings` dict passed to `run_experiment()`:

```python
run_experiment({
    "arrival_mean":       6.0,
    "critical_beds":      2,
    "standard_beds":      4,
    "selection_strategy": "ShortestExpectedTreatment",
    "n_replications":     3,
    "duration":           4000.0,
})
```

## What it does

* Patients arrive Poisson (exponential inter-arrival).
* Severity in [1, 10] routes patients to one of two pools:
  * Severity >= 7 -> critical care (triangular(20, 30, 45)).
  * Severity <  7 -> standard beds  (triangular(10, 15, 25)).
* One SimPy worker process per bed slot, so a pool with capacity *c* serves *c* patients in parallel (the parallel-vs-sequential check).
* Per-patient metrics: time in system, wait time, treatment time.
* Per-pool metrics: realised utilisation, mean queue length, mean wait, served count.
